WORKFLOW

四步，从图片到资产

下载后跟着做一遍，就能跑通完整流程。

STEP 01

导入参考图

三张独立视图，或一张 6 视图整图（自动切分为正/侧/顶/后/左/右）。

STEP 02

校正与重排

缩略图拖拽互换位置，自动加金/蓝边框高亮；统一缩放保证六视图比例一致。

STEP 03

体素重建

Oklab 感知色域 + K-means 生成 64 色共享调色板，自动剔除被包裹的内部体素。

STEP 04

导出交付

选定格式一键导出，直接拖进 Unity / Unreal / Godot / Blender / Aseprite。

8-DIRECTION SPRITE SHEET

OBJ · 2 MODES

GLB · VOX READY

需要联网吗？▾
重建与渲染全部在本地 CPU 完成，素材不出本机。需要联网的只有：登录、授权校验、激活、充值。
需要显卡吗？▾
不需要。预览渲染是纯 CPU 像素计算，集成显卡也能跑。
支持 macOS / Linux 吗？▾
当前仅发布 Windows 10/11 64 位版本。macOS / Linux 兼容但未做官方测试，后续视需求排期。
输入图有什么要求？▾
建议白底、主体居中、六视图同一像素尺度。支持三视图（正/侧/顶）或 6 视图整图（2 列 × 3 行）。
导出的模型比例准吗？▾
六视图由统一缩放因子处理，不按单图独立拉伸，忠实保留原画自身比例。
